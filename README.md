This is a programming language that is written entirely in pure C. When you finish writing source code and want to compile, you run the compiler binary in the terminal, it translates your lume code into C source code and then you have to use gcc, clang or any C or C++ compiler to compile the generated C code.
Important note: The current compiler can only and only handle single file projects.
If you want to see an example for the lume code, you can simply open the example directory and see the lume code inside the file pong.lm.
You can directly #include any header, lume will handle this easily.
The program named run is a simple game written in lume and uses the C game library Raylib, this is a proof that the language is usable and can handle C libraries flawlessly.
The program compiler is compiler program for the lume language. You can it by typing ./compiler in the terminal.
It is incredibly important to note that these binaries only run on the Linux distribution Ubuntu, if you want to use it on Windows, MacOS or any other OS, you have to compile it yourself.
